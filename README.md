# 🍔 Restaurant Menu Website

## 📌 About the Project

The Corner Bite is a simple and responsive restaurant website developed as a team project using HTML, CSS, Bootstrap 5, and JavaScript.

The website allows users to explore the restaurant's food and drinks menus through a clean and user-friendly interface.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Home page with restaurant branding.
- Food menu with item names and prices.
- Drinks menu with different beverages.
- Easy navigation between pages.
- Modern styling using Bootstrap and Font Awesome.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
